## Paper

1. **DMF: A Deterministic Memory Framework for Conversational AI Agents**

**Publish Date:**
2026-06-03

**一句话总结:**
针对对话AI智能体记忆管理提出确定性记忆框架DMF，用经典NLP和向量几何计算交互生存分数并基于交互计数衰减，在LoCoMo和LongMemEval上较Mem0实现零令牌准备上下文和5-242倍令牌节省，精度相当。

**Link:**
https://arxiv.org/abs/2606.03463

2. **Inducing Reasoning Primitives from Agent Traces**

**Publish Date:**
2026-06-03

**一句话总结:**
该研究提出从ReAct智能体轨迹中挖掘推理原语的方法，通过聚类常见推理模式构建类型化伪工具库，在RuleArena NBA、MuSR和NatPlan等任务上将准确率分别提升44、30和22个百分点，且推理成本低于AWM。

**Link:**
https://arxiv.org/abs/2606.02994

3. **SAGE: A Quantitative Evaluation of Socialized Evolution in Agent Ecosystems**

**Publish Date:**
2026-06-03

**一句话总结:**
引入社交化进化评估框架SAGE，在ML研究、经济规划和多人游戏三个领域对比SocialEvo与SelfEvo，发现共享历史能帮助瓶颈智能体突破，但最强智能体不获益，且过滤摘要优于原始日志，揭示社交收益依赖于抽象能力。

**Link:**
https://arxiv.org/abs/2606.03544

4. **When Helping Hurts and How to Fix It: Multi-Agent Debate for Data Cleaning**

**Publish Date:**
2026-06-03

**一句话总结:**
通过三个基准和四个模型家族实验揭示多智能体辩论在数据清洗中因批评诱导混淆导致生成质量下降但错误检测提升，推导辩论收益条件并提出对抗分离与证据门控生成，首次实现生成任务上显著超越单智能体。

**Link:**
https://arxiv.org/abs/2606.02866

9. **GRUFF: LLM Pronoun Fidelity, Reasoning, and Biases in German**

**Publish Date:**
2026-05-28

**一句话总结:**
该论文为德语构建了大规模代词忠实度数据集GRUFF，覆盖四种名词性别一致系统和四组代词（含新代词xier/en），评估LLM在有无干扰句时的代词复用能力；实验发现LLM对传统代词一致性强，但对新代词和干扰句鲁棒性不足，职业刻板印象相关性低，揭示德语性别包容语言推理与偏见问题。

**Link:**
https://arxiv.org/abs/2605.30214
